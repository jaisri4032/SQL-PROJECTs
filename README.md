--ONLINE BOOKSTORE MANAGEMENT SYSTEM--

The Online Bookstore Management System is a MySQL database project developed to manage books, authors, genres, customers, orders, and order details efficiently.
This project helps in storing and organizing bookstore information such as book details, author profiles, customer orders, and purchase history. The database uses relational tables with primary keys and foreign keys to maintain proper relationships between entities.

-->FEATURES:-
- Manage author and genre information
- Store book collections, prices, and stock counts
- Maintain customer records and registration details
- Track customer orders and transaction histories
- Generate reports using easy, medium, and hard SQL queries
- Perform advanced operations using joins, aggregate functions, and GROUP BY/HAVING clauses

-->TECHNOLOGIES USED:-
- MySQL
- SQL Queries
- ER Diagram Design
- GitHub for project management

-->DATABASE CONCEPTS USED:-
- CREATE, INSERT, SELECT
- WHERE clause and text operators (LIKE)
- Aggregate functions (SUM, COUNT, MAX)
- Joins (INNER JOIN)
- Grouping filters (GROUP BY, HAVING)
- Sorting parameters (ORDER BY DESC)
- Primary Keys and Foreign Keys
- ER Diagram Relationships

-->FILES INCLUDED:-
- bookstore_queries.sql
- bookstore_erd.png

--E-COMMERCE MANAGEMENT SYSTEM--

The E-Commerce Management System is a MySQL database project developed to manage marketplace stores, product inventories, customer checkouts, order tracking, and payment statuses efficiently.
This project helps in storing and organizing online marketplace information such as vendor shop details, product pricing, stock balances, customer transactions, and payment methods. The database uses relational tables with primary keys and foreign keys to maintain proper relationships between entities.

-->FEATURES:-
- Manage vendor store profiles and locations
- Store product inventory details, prices, and stock counts
- Maintain customer order logs and delivery cities
- Track specific item quantities purchased inside individual orders
- Handle payment methods and transaction completions
- Generate business reports using easy, medium, and hard SQL queries

-->TECHNOLOGIES USED:-
- MySQL
- SQL Queries
- ER Diagram Design
- GitHub for project management

-->DATABASE CONCEPTS USED:-
- CREATE, INSERT, SELECT
- WHERE clause and logical filters
- Aggregate functions (SUM, COUNT, MAX)
- Joins (INNER JOIN across multiple tables)
- Grouping filters (GROUP BY, HAVING)
- Sorting parameters (ORDER BY ASC/DESC)
- Primary Keys and Foreign Keys
- ER Diagram Relationships

- ecommerce_queries.sql
- ecommerce_erd.png
